# `results/` — recorded evidence

Every number quoted in the repository's documentation resolves to a file here. The evidence
table in `../CV_POINTERS_ML_SERVING_MONITORING.md` names these files explicitly, and
`../scripts/verify/verify_claims.py` fails if a documented figure cannot be found in them.

## Contents

| Path | Contents |
|---|---|
| `summary.json` | Aggregated result of every experiment, including the registered model's tags and its `training_fingerprint` |
| `training/last_training_summary.json` | The most recent training run: split sizes, per-model metrics, leakage report, environment, code and data versions |
| `drift/` | Per-scenario detection rates (`drift_experiment.json`), per-feature PSI, trial-level records, detection latency |
| `retraining/` | Promotion, rejection and rollback outcomes |
| `serving/` | Load-test results (pinned vs unpinned threads), the 24-check smoke test, rollback-through-serving, server logs |
| `tests/` | JUnit XML and a test-summary file |
| `plots/` | Drift figures generated by the drift experiment |
