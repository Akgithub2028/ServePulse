# `src/` — Python source

## Contents

- `mlserve/` — the platform package. Everything importable lives here; the scripts in
  `../scripts/` are thin entry points over it.
- `mlserve.egg-info/` — build metadata generated by `pip install -e .` (not source).

`pyproject.toml` declares `requires-python = ">=3.12"` and installs the package from `src/`
(the src layout prevents accidental imports of an uninstalled copy).

## Directive paths

| | |
|---|---|
| The package | `mlserve/` |
| Packaging and tooling config | `../pyproject.toml` |
| Entry points that use it | `../scripts/`, `../tests/` |
